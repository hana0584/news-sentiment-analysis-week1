# News Sentiment Analysis

**Description:**  
Quantifies the relationship between financial news sentiment and stock price movements using NLP and technical indicators.

**Tools:**  
Python, Pandas, TA-Lib, VADER, TextBlob, scikit-learn, Matplotlib, Seaborn, GitHub Actions.

**Overview:**  
- Perform EDA and topic modeling on news headlines.  
- Compute technical indicators (SMA, RSI, MACD, Bollinger Bands).  
- Score sentiment with VADER and TextBlob, then correlate with daily returns.  
- Deliver actionable investment strategies.
